好的设计是诚实的设计，
对于 web app 来说，
更诚实的设计是作为一个 tab 出现在浏览器里，
方便用户切换 tab 和别的 web app 一起使用。

electron desktop 把浏览器和 web app 打包起来了。
导致启动慢，占用系统资源。

deepseek-harness 刚开始时，
用本地 web app 的方式发布，让人耳目一新。
但是对于 deepseek 来说，这只是一个过度。
最终还是要作为独立的 desktop app 发布，
并且在尽力模仿 codex 的 desktop app。

我不应该模仿这个行为，
应该停留在「让人耳目一新」的本地 web app。
