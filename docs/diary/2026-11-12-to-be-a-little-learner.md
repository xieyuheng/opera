# 动机

几年前读了 "the little learner"，
但是由于没有实践，所以全忘记了。
现在，在 AI 的帮助下重读。

- 尝试用外部 markdown 文档做文学式编程，
  来帮助后续再次理解。

- 探索如何在不使用子类型与动态类型的条件下实现 learner？
  也许用 C 来实现，因为 C 没有这些语言特性。
  用 C 在不调用 malloc 的情况下实现 learner，
  也许未来可以接入 meta-lisp。

- 我们经常说，在机器学习中，重要的是数据。
  就大语言模型来说，其数据就是人类语言的语料本身。
  人类语言的语料，本身就是带有大量结构与标记的数据。
  核心想要理解的问题是「为什么大语言模型如此有效？」
