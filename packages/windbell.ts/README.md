# windbell.ts

AI agent inspired by [Peirce's Semiotics](https://plato.stanford.edu/entries/peirce-semiotics).

> * Thought is not a closed inner process, but a process of sign-interpretation;
>   every thought is a sign that points to another sign, and so on ad infinitum.
> * Human thought is the continuous process of sign-interpretation.
> * Man is a sign.

受[皮尔士符号学](https://plato.stanford.edu/entries/peirce-semiotics)启发的智能体。

> * 思维不是一个封闭的内在过程，而是一个符号解释的过程，
>   每一个思想都是一个符号，它指向另一个符号，如此无限延伸。
> * 人的思想就是符号的连续解释过程。
> * 人即符号。
